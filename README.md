# AI Harness Engineering Portfolio

This repository is a complete, reproducible submission for the three-part harness engineering project:

1. **Part A — Coding harness from scratch:** an OpenRouter-compatible coding agent with a safe tool loop, workspace sandbox, tests, and execution traces.
2. **Part B — DeepSeek Harness creator mode:** a DSH-style plugin runtime with seven plugins, including two plugins authored from scratch: `second_brain` and `project_memory`.
3. **Part C — Autoresearch ML harness:** an end-to-end experiment loop that changes a model configuration, trains it, evaluates it, keeps improvements, and records evidence.

The project is designed to run without paid credentials in **mock mode**, while supporting a real OpenRouter-compatible model when `OPENROUTER_API_KEY` is configured.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
python -m part_a.demo --task "Create a file named hello.txt containing Hello harness"
python -m part_b.demo
python -m part_c.autoresearch --iterations 6
```

For a live LLM run:

```bash
export OPENROUTER_API_KEY="your-key"
export OPENROUTER_MODEL="openai/gpt-4o-mini"
python -m part_a.demo --live --task "Inspect the starter project and explain its test strategy"
```

Never commit `.env` or API keys. The included `.env.example` is safe to copy.

## Architecture

```text
User task
   |
Part A Agent Loop ---- OpenRouter or deterministic mock model
   |                             |
   +--> policy-checked tools -----+--> trace.jsonl

Part B Creator Runtime --> plugin registry --> plugin results --> session log

Part C Research Loop --> candidate config --> train/evaluate --> metric gate
                                      ^             |
                                      +--- keep best
```

## Reproducibility

All demos are deterministic by default. Each run records configuration, seed, metric, elapsed time, and the decision (`keep` or `discard`). This makes the result inspectable rather than a screenshot-only claim.
